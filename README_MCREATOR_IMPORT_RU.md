# Mystical Creepy Tom (шаблон под MCreator 1.20.1 Forge)

Этот репозиторий содержит **готовый Java-файл** для вставки в MCreator как custom code.

## Что реализовано
- Tom (черная сущность-игрок по задумке; модель/текстуру назначаешь в MCreator).
- Редкие/иногда странные сообщения в чат.
- Появление вдалеке и смотрит на игрока.
- Если игрок отвернулся в первые 5 секунд — Tom исчезает.
- После 5 секунд пристального взгляда — случайные непредсказуемые действия.
- После этих 5 секунд Tom может сам исчезнуть через 10 секунд — 2 минуты.
- Если дотронуться до Tom — он исчезает.
- При спавне включается резкий «туман» (частицы CLOUD вокруг игрока).

## Как подключить в MCreator
1. Создай workspace Forge 1.20.1.
2. Создай Living Entity `Tom`.
3. Назначь полностью черную текстуру/модель гуманоидного типа.
4. Добавь Java class (custom code) и вставь содержимое `MCreator_Tom_CustomCode.java`.
5. В tick/update логике сущности вызывай методы `TomController`.
6. Для спавна по рандому вызови `spawnTomWithFog(...)` из global procedure (раз в N тиков).

## Важно
MCreator не всегда одинаково работает с прямым Java-кодом в зависимости от версии.
Если IDE MCreator ругается на конкретные импорты/сигнатуры, оставь логику и подправь имена методов под сгенерированный код твоего workspace.
